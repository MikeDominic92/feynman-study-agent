# Contributing

Thanks for helping make Feynman Study Agent better.

## Ground Rules

- Do not commit private course files, screenshots, paid textbook excerpts, or
  student data.
- Use sanitized fixtures for examples.
- Keep source-grounded claims tied to source references.
- Keep the tutor focused on learning, not answer dumping.
- Run the repo checks before opening a pull request.

```bash
npm run precommit:check
```

## Pull Requests

Please include:

- The learning workflow changed.
- The data shape or route changed.
- The tests run.
- Any privacy or copyright risk.
